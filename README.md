# AI Infra 学习笔记

学习《深入理解 AI Infra：量化分析与系统设计》（李博杰 著）过程中整理的问答与笔记。

- 原书仓库：<https://github.com/bojieli/ai-infra-book>
- 在线阅读：<https://bojieli.github.io/ai-infra-book/>

## 仓库内容

| 路径 | 说明 |
| --- | --- |
| `ai-infra-book/` | 原书仓库的本地精简克隆（去除多语言版本、PDF 生成、网站发布、存档等），仅作本地学习参考，不纳入版本管理 |
| `docs/` | 学习过程中的答疑文档，按 `<序号>-ch<章节号>-<问题关键字>.md` 命名（如 `00-ch01-显存估算.md`） |

## 学习方法

- 遇到问题先按第一性原理自行估算，再对照书中推导与 `ai-infra-book/calculations/` 的量化计算工具复算。
- 每个问题的分析过程与结论以中文记录在 `docs/`，主题相关的问题合并到同一文档。
